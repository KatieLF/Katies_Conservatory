There is a reason big services exist. Running digital services is hard work! But as I work on the concept of [[Ownership]], and claiming back the right to manipulate my digital properties, I find that making things my own and making things accessible are two different things.

Thusly begins self hosting services, not just files. I started with [[JellyFin]] which is where I starting running into the issues of being your own family's 24/7 IT support. My parents would call me during the work day or when I was spending time with my friends to ask a login question or a [[Tailscale]] question. It was a bit disruptive for a while but we've found a rhythm now.

The other kicker is I can't do maintenance whenever I want. There are other people using the Jellyfin and I need to make a quick announcement in the family group chat whenever the server goes down. It needs to be scheduled or loudly proclaimed so as not to disrupt the family movie night.

Photos is the next service to replace and the main user wants to transfer over face recognition data. The easiest (and likely best) option is [[Immich]], which I have been trial running for the past few months. It has a great UI and is easy to understand. The main problem now is figuring out facial recognition data. This is not an advertised feature on any of the self hosted services that I have been able to find. So two options, start naming faces from scratch or try to make it compatible with each other.

Facetial recognition data is not embedded within the photo, it is a separate file type
